# 研究室 出席管理(コアタイム対応版)

**GitHub Pages(画面) + Firebase Firestore(データ)** で動く、サーバー不要の Web アプリ。
どちらも無料枠で動き、PythonAnywhere のような定期的な延長作業は不要。データの変更は Firestore のリアルタイム同期で全端末に即座に反映される。

## 主な機能
| 機能 | 内容 |
|---|---|
| ステータス | 出席(緑)/ 離席(黄)/ 帰宅(赤)/ 不在(灰・初期値)/ 休暇(黒)。変更はすべて時刻付きで記録 |
| コアタイム | 既定は水木金 10:00–15:00(設定画面で変更可)。画面上部に「コアタイム中・終了まで◯:◯◯」等を表示 |
| 今日の状況 | コアタイムの日は各自の在室時間をバーで表示。コアタイム中に不在の人の席に「!」 |
| 集計(🔒管理者) | 週・月ごとに ◯達成 / △一部 / ✕不在 / 休、遅刻・早退回数、在室率。CSV出力可 |
| 休暇 | 期間指定で登録。登録日はコアタイム判定が「休」になる |
| コアなし日(🔒管理者) | 祝日・休講日などを登録すると集計から除外 |
| 管理者ロック | コアタイム集計とコアタイム設定はパスワードが必要(タブを閉じるまで有効) |
| ひとこと掲示板 | 30分/1時間/3時間/今日中/任意時間で自動消去。最新の一言は座席にも表示 |
| 自動リセット | 毎朝4:00以降に最初に開いた端末が、全員を「不在」に戻す(付けっぱなし対策) |

判定ルール:在室 = 出席 + 離席。在室が(コアタイム − 許容10分)以上で ◯。来室が開始+10分より遅いと遅刻、終了−10分より前に帰ると早退。「先生」は警告・集計の対象外。

## ファイル
| ファイル | 役割 |
|---|---|
| `index.html` + `js/index.js` | 座席表・ステータス変更・掲示板・今日のコアタイム状況・休暇カレンダー |
| `stats.html` | コアタイム集計(週/月、CSV) |
| `settings.html` | メンバー・休暇・コアタイム設定・コアなし日 |
| `js/core.js` | 日本時間の扱いとコアタイム判定(Firebase 非依存) |
| `js/store.js` | Firestore の読み書き・リアルタイム購読 |
| `js/firebase-config.js` | Firebase の接続設定(**要記入**) |
| `firestore.rules` | Firestore のセキュリティルール(コンソールに貼る) |

## 初回セットアップ

### 1. Firebase プロジェクトを作る(無料・カード登録不要)
資産管理アプリとは**別のプロジェクト**にする(研究室のみんなが読み書きするため)。
1. https://console.firebase.google.com/ →「プロジェクトを追加」(例:`lab-attendance`)。Google アナリティクスはオフで良い
2. 「構築」→「Firestore Database」→「データベースの作成」→ ロケーション `asia-northeast1`(東京)→ 本番環境モード
3. 「ルール」タブに `firestore.rules` の中身を貼り付けて「公開」
4. 「構築」→「Authentication」→「始める」→「Sign-in method」で「匿名」を有効化
5. 歯車 →「プロジェクトの設定」→「マイアプリ」の `</>` でウェブアプリを登録 → 表示された `firebaseConfig` の値を `js/firebase-config.js` に貼る

### 2. GitHub Pages で公開する
1. GitHub に新しいリポジトリ(例:`lab-attendance`)を作り、このフォルダの中身を push
   (`旧出席アプリ一部.rtf` は不要なので含めなくて良い)
2. リポジトリの Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `(root)` にして保存
3. 数分後に `https://murabitopit.github.io/lab-attendance/` で開けるようになる

### 3. メンバー登録
公開ページの「⚙️ 設定」を開くと、メンバーが空のときだけ「一括登録」ボタンが出る。押すと旧アプリの15名(2026/11/10 時点)が登録される。

### 4. 旧アプリから切り替え
みんなに新しい URL を案内する。旧 PythonAnywhere 版は放置すれば期限切れで止まるだけなので、特に作業は不要。

## 無料枠について
Firestore 無料枠(Spark プラン)は 1日あたり 読み取り 5万回 / 書き込み 2万回。
15人前後が1日中開きっぱなしにしても数千回程度なので十分収まる。
無料枠を超えても課金はされず、その日の残りが使えなくなるだけ(クレジットカード未登録のため)。

## 注意
- 管理者パスワードはブラウザ側での簡易ロック(サーバーが無いため)。コードにはパスワードのハッシュのみ置いている。
  パスワードを変えるときは `printf '%s' 新パスワード | shasum -a 256` の結果で `js/common.js` の `HASH` を置き換える。
- ログイン無しで誰でも閲覧・編集できる設計(旧版と同じ)。URL は研究室外に出さない。
- 時刻の記録は Firebase のサーバー時刻を使うので、端末の時計がずれていても記録は正確。
- コアタイム判定は日本時間で行うので、端末のタイムゾーン設定には影響されない。

## ローカルで確認したいとき
`js/firebase-config.js` を設定済みなら、このフォルダで `python3 -m http.server` を実行し http://localhost:8000 を開く。
